Single module `shortener.py`, standard library only (zero install, runs offline); layers top to bottom:
1. HTTP adapter `make_app` (WSGI): routing, JSON parsing with a 4 KB body cap, error-to-status mapping, per-client rate limiting on writes, no internals leaked on 500.
2. `ShortenerService`: validation, 7-char base62 codes from `secrets`, retry on collision (5 tries, then 503), idempotent shorten for permanent links, TTL expiry, best-effort click analytics, injectable clock for deterministic tests.
3. `LinkRepository` (SQLite): tables links(code PK, url, created_at, expires_at, custom) and clicks(code FK ON DELETE CASCADE, ts, referrer); all SQL parameterised; one connection behind a lock; WAL for file databases.
4. Web UI: one self-contained `ui.html` (inline CSS and JS, no framework, no external resources) served at `GET /` next to the module; data is rendered with textContent only, and the server sends a hash-based Content-Security-Policy (`csp_for`) so injected markup cannot execute.
Decisions: WSGI over a framework (no dependency, trivially testable); production direction is FastAPI + Postgres + Redis-backed limiter. Errors are typed exceptions mapped to stable error codes. Rejected URL classes: non-http(s), credentials, private/loopback hosts, non-ASCII, whitespace/control characters (prevents header injection).
